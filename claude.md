# Project: Orlando Fitness & Weight Loss — SEO Test Site

## Purpose
This is a test/learning site to practice an SEO content workflow: researching
top-ranking pages for a target keyword, then drafting a page that matches
what's working while sounding human-written, not AI-generated.

## Niche & Location
Weight loss and exercise content, localized to Orlando, Florida. Content
should reference Orlando-specific context where natural (heat/humidity,
local parks, seasonal patterns) rather than reading as generic fitness
content with "Orlando" pasted in.

## Voice
- Practical, encouraging, no hype or miracle-cure language
- Write like a knowledgeable local trainer, not a listicle content farm
- Short paragraphs, scannable subheadings, no fluff intros

## Page structure conventions
- One H1 per page, matching the target keyword naturally
- Descriptive H2s that map to the subtopics competitors cover
- Meta title under 60 characters, meta description under 155 characters
- Include a short FAQ section at the bottom targeting "People Also Ask"
  style questions when relevant

## Technical
- Plain HTML/CSS, no build tools or frameworks
- Semantic HTML5 (header, main, article, section tags)
- Mobile-first responsive CSS
- Every page needs a title tag, meta description, and one optimized image
  with descriptive alt text

## What NOT to do
- No specific medical, dosage, calorie, or diet-plan claims — this is
  marketing/informational content, not personalized health advice
- No fabricated stats, testimonials, or business claims (this is a test
  site, not a real business — keep placeholder content clearly generic)
- Don't reproduce text from competitor pages — read their structure and
  topic coverage, then write original content
